# МТК 38 — план до подачи

Статус: 2026-08-01. Источник новых данных — `assets/mtk38/sources/Ленин на языках народов мира.doc`
(147 изданий / 123 уникальных языка, живой Unicode, 33 фото обложек внутри файла).

## Модель данных

Ключевое: документ описывает **издания**, а не языки. Один язык → N изданий
(испанский — 9 стран, английский — 5, арабский — 5, немецкий — 4).

```
data/mtk38.json               язык  (канон: написание, письмо, семья, ареал, гео, вес)
data/mtk38-publications.json  издание (язык × страна: заглавие, город, издательство, год, обложка)
```

Связь по `lang_id`. Канон остаётся единственным источником написаний; издания —
отдельный слой, подключается опционально (варианты без карточек его не грузят).

## Э2 · Карточка (единая для всех вариантов)

Расширить `mtk38-v3/engine/card.js` блоком «Издание»: обложка, заглавие на языке,
русский перевод, город / издательство / год. Если изданий несколько — переключатель
внутри карточки.

Вынести карточку в общий модуль и подключить **во все** варианты: v3 `globe`/`rain`/`map`
и v2 `studio`/`map` (у v2 сейчас своя разметка `.mcard` — убрать дубль).
Тач: без hover, крупные зоны, закрытие ✕ / Esc / тап вне.

## Э3 · Карта — унификация с другими МТК

- Перевести `mtk38-v3/map.html` и `mtk38-v2/map/` с equirectangular на
  `MtkProjection.WinkelTripel` (`assets/shared/lib/projection.js`), аспект только из
  `WT.ASPECT`, порядок аргументов `(lat, lng)`.
- Подложка: geojson перерисовать через WT.
  ⚠ Растровые текстуры `earth-relief.jpg` / `earth-physical.jpg` — equirect, под WT
  не встают. Либо перепроецировать разово офлайн (python), либо в WT-режиме отказаться
  от растра и оставить контурную подложку.
- Заявка координатору: запись в `COORDINATION.md` + coord-чат.

## Э4 · Изолированная сборка

`mtk38-build/` — самодостаточная папка под подачу и киоск: выбранные варианты,
карточка, данные, шрифты, обложки. Офлайн, без зависимости от `assets/shared/`
и координаторского хаба; свой переключатель вариантов.
