# legacy — генераторы до июльского сплита v2

Эти скрипты собирали одностраничные `mtk38-v2/{globe,map,studio,validate,app,
render-test,quotes-test}.html`. При рефакторинге «фронт/бэк» (2026-07-08) страницы
переехали в slug-папки (`studio/`, `map/`) и `back/`, а часть слилась в единый
арт-объект — файлов, в которые они пишут, больше нет.

Запуск любого из них создаст устаревший дубль рядом с живой страницей.
Лежат здесь как история приёмов генерации; в `build_all.py` больше не входят.
