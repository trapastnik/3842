### Что изменилось в схеме `data/mtk41.json`

| Поле | Что это |
|------|---------|
| `kind` / `kind_ru` | Тип объекта: `sculpture` (247), `bust` (20), `relief` (9), `rock-image` (2), `geoglyph` (2), `rock-carving` (1), `steel-silhouette` (1), `plaque` (1). Проставлено **всем** записям, включая 236 старых (по эвристике из `size_raw`). |
| `wave` | `"first"` — 40 памятников волны 1919–1927. |
| `makers` | Не-скульпторские роли: модельщик, формовщик, литейщик, маляр-декоратор, местный мастер, учитель. В ранней волне это содержательно — памятники делали рабочие своих же фабрик, а не академики. |
| `prev_source` | У обогащённых записей — исходный источник до слияния. |

**Высоты** (`heights.json`, +33 записи) считаются только для `sculpture`/`bust`/`relief`/`plaque`. Для геоглифов понятие «фигура + постамент» не работает — их габариты живут только в `size_raw`, и в масштабных прототипах (`mtk41-scale`, `mtk41-silhouettes`) они уходят на процедурный фоллбэк. Иначе геоглиф 590 м раздавил бы шкалу.

### Сшивка со старыми папками

Четыре памятника из новой таблицы — это те же объекты, под которые фото собирались ещё в первом наборе из 18 ID. Взяты их прежние id, чтобы 8 уже собранных фотографий подключились обратно: `ufa-1924-larionov`, `moscow-oktyabrskaya-1925`, `nizhny-tagil-1925`, `chelyabinsk-aloe-pole-1925`. Запись `kaluga-1925` уже была в корпусе с 2026-06-29 — она **обогащена**, а не продублирована.

### Что осталось нерешённым

- **Фото музея в Поронине** (`poronin-1950/context/muzey-lenina-poronin.jpg`) — на снимке здание музея, самого памятника в кадре нет. Положено в `context/`, а не в `photos/`, чтобы прототипы не выдали его за изображение памятника. Возможно, это материал для МТК 39/40, а не для 41.
- **Координаты всех 48 новых записей — `coords_verified: false`**, взяты по центрам населённых пунктов и приблизительным точкам объектов (скалы, геоглифы). Для геоглифов и наскальных изображений это заметная погрешность: объект стоит не в городе, а в 50 км от села.
- **Шесть записей без атрибуции автора** (`verkhniy-fiagdon-1924`, `mozhaysk-1924`, `kulebaki-1925`, `blagoveshchensk-rb-geoglif-1970`, `ukhta-vetlosyan-1970`, `kharare-1980`) — в источнике авторы не указаны. Для `mtk41-authors` это записи вне всех групп.

## Лицензионная сводка

Все 46 фотографий — под свободными лицензиями:

- **CC BY-SA 4.0** — ≈ 70% (большинство современных фото из Wikimedia Commons)
- **CC BY 2.0 / 3.0 / 4.0** — ≈ 15%
- **Public Domain / CC0 / Общественное достояние** — ≈ 15% (советские марки, архивные фото до 1955 г.)

Фото с лицензией «Добросовестное использование» / fair-use фильтр исключил
автоматически. Это значит: **все собранные фото можно использовать в музейной
экспозиции** при соблюдении условия CC-BY (указать автора и лицензию). См.
поля «Автор» и «Лицензия» в каждом `photos.md`.

3D-модели на Sketchfab почти все **только для просмотра** (без скачивания).
Перед использованием в прототипе — связаться с авторами либо сделать собственную
фотограмметрию.

- **Меркуров «Смерть вождя»** — все 4 фото действительно скульптурной группы (а не путаниц с другими его работами).

## История поиска

- Источник фото №1: **Wikimedia Commons** (api.php, list=search и list=categorymembers).
- Источник фото №2: **ru.wikipedia.org local file repository** — многие старые фото советских памятников лежат не на Commons, а локально на ruwiki. Файлы CC BY-SA, но сам fetcher этот fallback изначально пропускал — критический баг найден в процессе.
- Источник 3D: **Sketchfab v3 API** (без OAuth, только публичные модели).
- Фильтры: (а) расширение `.jpg / .jpeg / .png / .tif`; (б) обязательно слово
  «Ленин / Lenin / Ульянов / Володя / Ильич» в имени или описании (исключение —
  Меркуровская «Смерть вождя»); (в) исключение лицензий «Добросовестное использование»;
  (г) минимальная ширина 600 px.
