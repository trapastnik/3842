# Опись настроек прототипов (обязательное приложение к миграции на киоск-платформу)

Составлена координатором 2026-08-03 полным обходом всех прототипов. Правило: при сборке
mtkXX-app КАЖДАЯ строка класса А из своего МТК либо переезжает в settings-схему сцены
(канон v1.2, PLAN-KIOSK), либо в коммит-сообщении явно указывается «снята: <причина>».
Молчаливая потеря настроек недопустима (прецедент — пилот 42, см. «Риски потери» внизу).

Классификация: **(А)** — операторская настройка вида → в декларативную схему сцены
`settings:[...]` + `applySettings(values)`; ядро рисует в сервис-панели, хранит в
`localStorage["mtkXX-kiosk"].scenes[id]`. **(Б)** — посетительский контент-контрол →
остаётся в UI сцены, сбрасывается `reset()` по idle; персисты снять. **(В)** — дубль
киоск-уровня → отмирает, функцию несёт ядро.

## Риски потери (пилот 42 против прототипов 42) — ДОЛГ ЗАКРЫТ 2026-08-03

Из 45 (уточнено: 55) операторских настроек прототипов 42 в пилоте были живы 4. Потеряно: pendulum — 22 (плотность лет, кривая 3, сглаживание, 3 тумблера отображения, типографика 9, дизайн карточки, «сжать Канон»; плюс ПОСЕТИТЕЛЬСКИЙ фильтр категорий исчез со сцены — регресс функции); map — 15 (проекция, кадр 8, толщина границ, города 2, чувствительность колёсика, типографика 6 минус перенесённые); timeline — 17 (вся типографика + высоты, getSetting не вызывается вовсе); archive — тумблер дизайна карточки.
